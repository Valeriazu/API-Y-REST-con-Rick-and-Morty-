# API REST con Rick and Morty 🛸

Aplicación web desarrollada con Node.js y Express para consumir e interactuar con datos de la API de Rick and Morty.

## 🚀 Tecnologías utilizadas

- **JavaScript (ES6+)**
- **Node.js**
- **Express**
- **HTML5 / CSS3**

## ⚙️ Funcionalidades

- Conexión y consumo de endpoints de la API pública.
- Renderizado dinámico de personajes e información relevante.
- Manejo de rutas y peticiones backend/frontend.
